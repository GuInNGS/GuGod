股神模拟器（GuGod）
====================

一个纯前端 A 股盲做训练小游戏：随机抽一段真实历史 K 线（标的与日期全程隐藏），
你每天收盘只能做一件事——买入或观望 / 持有或卖出，成交永远在下一个开盘。
结算揭晓标的，和"同期一直拿着"比一比：你到底是股神，还是不如不动。

在线玩
------
GitHub Pages 部署，仓库根目录的 index.html 就是全部（单文件、无构建、无后端）。

本地跑
------
    cd 本目录
    python -m http.server 8931
    浏览器打开 http://127.0.0.1:8931/index.html
（行情数据现拉腾讯接口，需要联网；直接双击 file:// 打开一般也能跑，接口有 JSONP 兜底。）

玩法
----
- 开局随机抽一只股票 + 2013 年至去年之间的随机起点，30 或 60 个交易日为一阶段
- 盲做：标的与日期隐藏，结算才揭晓；行情卡只给当日上证涨跌幅、不给点位（防剧透年代）
- 每天收盘二选一：空仓「买入/观望」、持仓「持有/卖出」；成交价 = 次日开盘价，T+1
- 费用：佣金万3（最低5元）+ 印花税万5；不设杠杆、不做空
- 阶段末可续 30 天（最多到 750 根），也可随时"溜了"按收盘价结算
- 快捷键：←/A 买入·持有，→/D 观望·卖出，空格 下一局

主题抽局（顶栏「主题」下拉）
--------------------------
- 随机：全池 5146 只、全年代
- 股灾年代：只抽 2015-06 ~ 2016-01（股灾+熔断段）
- 阴跌年代：只抽 2018 全年（阴跌熊市段）
- 抄底陷阱：只抽起点前 60 个交易日已深跌 ≥25% 的票——抄底永远不是底
主题只约束抽哪段历史，票与起点仍然随机。

结算口径
--------
- 策略收益：本局期末权益 / 起始权益 - 1（账户跨局连续，从 10 万起步）
- 个股持有：同期第一天买入一直拿着
- 超额收益：策略 − 个股持有（比的是"你做来做去不如拿住吗"，不是跟大盘比）
- 同期基准：统一为上证指数（用户 2026-11-02 定）；另给"个股vs大盘 = 持有 − 基准"
- 最大盈利 / 最大回撤：本局权益曲线的峰值浮盈与最深回撤（峰从本局起始权益起算）

数据与存储
----------
- 行情：腾讯接口（实时/日线，多 host 并发抢跑 + JSONP 兜底），基准与当日大盘共用上证序列
- 记录：浏览器 localStorage（复盘记录最多 200 条，每条自带整段 K 线可回看）
  - 键名 kline_practice_records_v1（记录）/ kline_account_v1（账户）/ kline_account_archive_v1（归档）
- 复盘记录带 ver 字段（本文件对应 v1.4.3）；旧记录缺字段时按可算口径现场重算
